# Integration: shared (AAA, TST, hellenicgfx)

Generated by eu4unitgen. Not loaded by the game.

Copy the rest of this package folder into your mod's root folder as it is: those are new files.
The changes below go into files your mod already has (or copies of vanilla's), which
eu4unitgen never writes. Merge them by hand. `eu4unitgen test-mod` applies them to copies
inside the throwaway test mod only.

## 1. Country files

This set is shared by 2 tags through one sprite pack. In each tag's country file
(the file `common/country_tags` gives for it), set the same lines:

- AAA: `common/countries/Alpha.txt`
- TST: `common/countries/Testland.txt`

```
graphical_culture = hellenicgfx
historical_units = {
	hr_shared_infantry_1
	hr_shared_cavalry_1
	hr_shared_artillery_1
	hr_shared_infantry_2
	hr_shared_cavalry_2
	hr_shared_artillery_2
	hr_shared_infantry_3
	hr_shared_cavalry_3
	hr_shared_artillery_3
	hr_shared_infantry_4
	hr_shared_cavalry_4
	hr_shared_artillery_4
}
```

`color` is left as it is.

## 2. MIL technology enables

Add to `common/technologies/mil.txt` (if your mod has none yet, start from a copy of vanilla's).
The index counts `technology = { }` blocks in the file from 0.

- technology 1:
```
	enable = hr_shared_infantry_1
	enable = hr_shared_cavalry_1
```
- technology 3:
```
	enable = hr_shared_infantry_2
	enable = hr_shared_cavalry_2
	enable = hr_shared_artillery_2
```
- technology 5:

- technology 6:

```
	enable = hr_shared_cavalry_4
```

- technology 7:
```
	enable = hr_shared_artillery_1
```

## 3. Graphical culture list

Add one line per new culture to `common/graphicalculturetype.txt` (if your mod has none yet, start from a copy
of vanilla's; UNVERIFIED but expected: the mod's copy replaces the vanilla list):

```
hellenicgfx
```

## 4. Unit colours

Units are tinted with `color1`-`color3` from `common/country_colors/00_country_colors.txt` (not the map `color` above).
Put these entries in your mod's copy of that file, replacing any existing entry for the same tag
(if your mod has none yet, start from a copy of vanilla's):

```
AAA = {
	color1 = { 150 20 30 }
	color2 = { 210 170 40 }
	color3 = { 25 35 90 }
}
TST = {
	color1 = { 20 60 200 }
	color2 = { 240 200 30 }
	color3 = { 20 20 20 }
}
```
