Generated by eu4unitgen. Not loaded by the game.

Copy the rest of this package folder into your mod's root folder as it is: those are new files.
The changes below go into files your mod already has (or copies of vanilla's), which
eu4unitgen never writes. Merge them by hand. `eu4unitgen test-mod` applies them to copies
inside the throwaway test mod only.

## 1. Country file
In `common/countries/Haida.txt` (the file `common/country_tags` gives for HDA), set:

```
graphical_culture = hellenicgfx
historical_units = {
	hr_macedonian_test_infantry_1
}
```

`color` is left as it is.

## 2. MIL technology enables

Add to `common/technologies/mil.txt` (if your mod has none yet, start from a copy of vanilla's).
The index counts `technology = { }` blocks in the file from 0.

- technology 1:
```
	enable = hr_macedonian_test_infantry_1
```

## 3. Graphical culture list

of vanilla's; UNVERIFIED but expected: the mod's copy replaces the vanilla list):
